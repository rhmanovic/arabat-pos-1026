# أخطاء في الكود اكتُشفت أثناء كتابة الدليل

هذا الملف سجل للخلل الذي وُجد في الكود أثناء التحقق من نصوص الدليل. لا يُصلَح شيء هنا: الدليل
يصف السلوك الحالي، وكل بند ينتظر قرار المالك وجدولته في التطوير.

- **الخطورة:** عالية = قد يضيّع مالًا أو يمنع إجراءً ماليًا أو يضعف الأمان؛ متوسطة = يربك الموظف أو
  يعطي معلومة خاطئة؛ منخفضة = نص أو عرض أو راحة استخدام.
- **الحالة:** مفتوح، حتى يُصلَح ويُراجَع القسم المتأثر.
- **القسم:** القسم الذي اكتُشف فيه البند (وأقسام أخرى يذكرها).
